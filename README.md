PDF to Flashcard Generator
A full-stack SaaS application that converts PDF documents into interactive flashcards for studying.


Show Image
✨ Features

PDF Upload & Processing - Extracts content from PDF documents
Auto Flashcard Generation - Creates study flashcards from content
User Authentication - Secure login and user management
Progress Tracking - Save and review flashcard sets
Responsive Design - Works on desktop and mobile

🛠️ Tech Stack
Next.js | TypeScript | React | Tailwind CSS | Neon DB | Clerk
